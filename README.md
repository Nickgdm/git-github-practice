Exercício introdutório de controle de versão que propõe clonar um repositório, editar o arquivo `dados.txt`, registrar a alteração em um commit e publicar o trabalho no GitHub.

══════════════════════════════════════════════════════

## Sobre o projeto

A atividade apresenta o fluxo básico de trabalho com Git, desde a obtenção do projeto até o envio das alterações para um repositório remoto.

══════════════════════════════════════════════════════

## Objetivos

- Praticar clone, edição de arquivos e commits.
- Entender o fluxo básico de trabalho com Git.
- Publicar alterações em um repositório remoto.

══════════════════════════════════════════════════════

## Tecnologias e ferramentas

- Git
- GitHub
- Arquivo de texto `dados.txt`

══════════════════════════════════════════════════════

## Pré-requisitos

- Git instalado e configurado.
- Conta GitHub e acesso ao repositório.

══════════════════════════════════════════════════════

## Como executar

Clone o repositório e entre na pasta:

```bash
git clone https://github.com/Nickgdm/aula-git-ebac.git
cd aula-git-ebac
```

Edite o arquivo `dados.txt` e registre a alteração:

```bash
git add dados.txt
git commit -m "Modificando o arquivo de dados"
git push
```

O comando `git push` requer que o repositório remoto e as permissões estejam configurados corretamente.

══════════════════════════════════════════════════════

## Boas práticas

- Utilizar mensagens de commit relacionadas à alteração.
- Versionar somente os arquivos necessários.
- Separar o arquivo da atividade de suas instruções.
- Evitar publicar dados pessoais ou sensíveis.

## Aprendizados

A atividade permite praticar o fluxo básico de versionamento com Git e GitHub: clonar um repositório, editar arquivos, preparar alterações, criar commits e publicar mudanças em um repositório remoto.
